# 交付清单与质量检查

## 按实际任务交付

不是每次都制作所有格式；用户要求哪些模式就完成哪些，缺依赖时明确哪一项没有完成。

| 类别 | 内容 | 要求 |
|---|---|---|
| 预览 | 正面/背面并列，必要时系列总览 | 无裁切线，适合屏幕；不能作为印刷稿替代 |
| 设计母稿 | 实际可编辑工程文件、矢量排版或独立图层 | 人物、背景、Logo、文字、工艺分层；无法导出工程时明确格式限制 |
| 干净图稿 | 每卡正面含出血 PNG/TIFF/PDF、每队通用背面 | 物理规格明确，正反一致，无辅助线 |
| 成品视图 | 裁到 63.5 × 88.9 mm 的预览图 | 与含出血稿分开命名，避免误送印 |
| 单卡印刷 | 带裁切线且页面框正确的 PDF | 用户或印厂需要时提供 |
| 同页粘贴 | A4 PDF：每行同一卡正反配对 | 单面印，100%，不镜像，不误标折叠版 |
| 双面印刷 | A4 PDF：每张纸正反交替 | 标注 long/short、配对矩阵和校准状况 |
| 工艺文件 | 镭射材料说明、所需白墨/箔/UV 蒙版 | 仅实际制作并完成印厂规范检查时列为生产文件 |
| 交付说明 | 来源、尺寸、版本、色彩、打印设置、缺项、质检结论 | 真实写出限制，不用“全部通过”掩盖未测项 |

推荐文件名：`项目-卡ID-风格-front-bleed-v01.png`；`项目-队ID-back-common-bleed-v01.png`；`项目-a4-paste-v01.pdf`；`项目-a4-duplex-long-v01.pdf`。内部 ID 不代表球员姓名。不要在公共包里包含人像原图、私人资料或未获分发授权的字体。

## 人物与资料检查

- [ ] 已看过原图和批准版本，对比了人脸、年龄感、体型、队服、号码及手部。
- [ ] 无额外背景人物、复制球员、残留抠图边或错误肢体。
- [ ] 多时期均为真实素材，顺序和标签有来源；无“成长轨迹”默认禁用文案。
- [ ] 姓名、队名、背号、赛季、数据均逐项有来源；未知字段已省略。
- [ ] 自定义卡号与球衣号分清；无虚构荣誉、签名或官方认证。

## 视觉与背面检查

- [ ] 实际尺寸可读，像收藏卡而非宣传海报；人物是第一视觉中心。
- [ ] Logo 与原文件一致，无拉伸、猜造或生成变体。
- [ ] 同队通用背面未混入单个球员字段；跨队背面正确映射。
- [ ] 镭射装饰未污染肤色、眼睛、队标或文字；模拟与实体工艺标注准确。
- [ ] 辅助框、占位文字、null、测试编号没有出现在正式卡面。

## 印前检查

- [ ] Trim 为用户确认尺寸；每边出血达到 3 mm 或供应商要求。
- [ ] 核心信息处于安全区，圆角附近无关键内容。
- [ ] 栅格素材有效 PPI 已检查；未以改 DPI/放大冒充高质量。
- [ ] 裁切线在出血外，无误裁到成品；单卡页面框正确。
- [ ] 字体已嵌入/转曲，中文不乱码、不缺字；颜色与 ICC 状态如实记录。
- [ ] A4 MediaBox 为 210 × 297 mm，不自动缩放；各稿与标记不重叠、不超出可印区。
- [ ] 同页粘贴的每一对正确，均正读；不是误做双面或折叠版。
- [ ] 双面 long/short 与驱动一致，背面位置正确，文字/Logo 未镜像，空位保留。
- [ ] 已打印校准页并量尺、透光；或明确写“仅数字几何检查，未验证设备对位”。
- [ ] 工艺蒙版尺寸、原点、命名、专色与叠印规则已按印厂要求检查；否则只列为待确认素材。

## 质检结论用语

每项记录为 `通过`、`失败`、`未验证` 或 `不适用`，可附证据路径。自动拼版报告只证明文件与几何检查，不证明照片身份、Logo 授权、颜色效果、印刷机精度或真实工艺。

交付前打开渲染后的每页，检查首末页、所有卡图/文字与配对。若没有渲染能力，明确未完成视觉校验，不用“PDF 文件可打开”替代。制作工具或素材缺失时交付已完成部分及可执行后续步骤，不编造下载地址或验证结果。
