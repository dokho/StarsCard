# Production workflow

This entry preserves the repository's original reference path. Use only the focused references needed for the task.

1. [Input specification](input-spec.md): real photos, optional facts with sources, single/team/growth type, orientation and delivery mode. Missing names, numbers and positions are omitted.
2. [Photo fidelity](photo-fidelity.md): prefer actual source-photo composition. Team members are all subjects, not background people to remove.
3. [Design and styles](design-styles.md): original card frames, retro/editorial/holographic options and common team backs. The existing [style catalog](style-catalog.md) and [style system](style-system.md) remain available on request. Internal style labels are not printed by default.
4. [Print production](print-production.md): portrait 63.5 x 88.9 mm or landscape 88.9 x 63.5 mm, 3 mm bleed, 5 mm safe area, target 300 ppi. Printer templates override defaults. 600 ppi masters remain optional; 0.125 inch (3.175 mm) bleed is a different supplier setting and must not be silently mixed with 3 mm.
5. [Tooling](tooling.md): optional Python imposition. Portrait A4 2x2 is implemented; landscape single-card PDFs are supported, while landscape A4 paste/duplex needs a different layout.
6. [Delivery QA](delivery-qa.md): inspect actual exports and label unverified items. [Capabilities](capabilities.md) governs what the host can really produce.

Use a quiet shared back across front-style variants unless requested otherwise. A team-common back contains no individual player facts. Exact text and original Logos belong in deterministic layout where available. Missing tools result in an honest prompt/layout handoff, not a fabricated finished bitmap or link.
